# Geospatial Data Mining: Halte Transjakarta

Analisis lokasi halte Transjakarta: visualisasi peta penduduk Jakarta,
zona gerai minimarket (buffer 500 m), jarak Haversine, dan Agglomerative Clustering.

## Isi
- `Tugas7_Geospatial_Data_Mining_final.ipynb`: notebook analisis
- `Data Lokasi Halte.xlsx`, `Jumlah Penduduk Jakarta 2023.csv`, `jakarta-simplified-topo.json`: data

## Cara menjalankan
pip install geopandas shapely scikit-learn matplotlib openpyxl
Buka notebook dari folder yang sama dengan file data, lalu Run All.
